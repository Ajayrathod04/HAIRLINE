# UI direction
Function over decoration: every colour carries a state. Colours below are estimated from the reference images supplied by the author; no logos or artwork were copied.

| Token | Value | Use |
|---|---|---|
| cream | #F4EBDD | page base (calm, from the cream/saffron type specimen reference) |
| ink | #111113 | text, 3 px outlines, hard shadows (neo-brutalist portfolio reference) |
| lime | #D7FF3F | pass, primary action, measured (author's poster palette) |
| saffron | #F2A93B | re-shoot, warning |
| coral | #FF5A6E | escalated, denied, dispute |
| violet | #5B2EFF | authorised, focus ring |
| blue | #2A2EA8 | trace/audit panels (arcade-site reference) |

Type: Archivo expanded black italic for headlines (extended heavy italic like the Spotify-style posters; Spotify's own typeface is proprietary and not used), Inter for text, JetBrains Mono for numbers and hashes. Screens: Try it (sample or camera, result, gates, trace), Cases (ranked, role-aware forms, CSV import), Case (governance, width chart with error bars, visits, audit), About (how it works, simulated vs estimated, live policy). Accessibility: skip link, visible focus, aria-live results, text labels with every colour, reduced-motion support, mobile-first layout. **Not yet verified in a real browser** in the build sandbox (only runtime smoke-tested with a fake DOM): open it on your phone and desktop before recording.
